# Data

| File / folder | What | Source and licence |
|---|---|---|
| `tabular/diabetes.csv` | Pima Indians Diabetes: 768 patients x 8 features, label `diabetes` | National Institute of Diabetes and Digestive and Kidney Diseases via the UCI repository (Smith et al., 1988). Copy taken from github.com/jbrownlee/Datasets |
| `tabular/spect.csv` | SPECT Heart: 267 patients x 22 binary image features, label `diagnosis` | UCI repository (Kurgan et al., 2001), CC BY 4.0. Copy taken from PMLB (github.com/EpistasisLab/pmlb) |
| `MNIST/`, `FashionMNIST/` | Downloaded automatically by torchvision the first time an experiment or the notebook needs them (about 60 MB) | MNIST (LeCun et al., 1998); Fashion-MNIST (Xiao et al., 2017, MIT licence) |

`../assets/demo_samples.npz` holds 300 MNIST and 300 Fashion-MNIST test images so the live app works without internet.
